# lilvo DS Micro — project site

Static site for lilvo DS Micro, a tiny dual-screen clamshell handheld in development.

- `index.html` — home page
- `log.html` + `log/` — build log
- `style.css` — shared styles for the log pages
- `images/`, `fonts/` — assets

No build step: serve the folder as-is (e.g. Cloudflare Pages, output directory `/`).
